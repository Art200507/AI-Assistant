# Raspberry Pi 4 Model B — Technical Specifications

Source: raspberrypi.com official specifications page.

## Processor & Memory
- Broadcom BCM2711, Quad core Cortex-A72 (ARM v8) 64-bit SoC @ 1.8GHz
- RAM available in multiple tiers: 1GB, 2GB, 3GB, 4GB or 8GB LPDDR4-3200 SDRAM

## Connectivity
- 2.4 GHz and 5.0 GHz IEEE 802.11ac wireless, Bluetooth 5.0, BLE
- Gigabit Ethernet

## Ports & Interfaces
- USB: 2 USB 3.0 ports; 2 USB 2.0 ports (all USB-A, host-only — cannot be used to connect to another computer as a data/network device)
- GPIO: Raspberry Pi standard 40 pin GPIO header (fully backwards compatible)
- Display: 2 x micro-HDMI ports (up to 4kp60 supported) — NOT standard/full-size HDMI
- Camera/Display: 2-lane MIPI DSI display port, 2-lane MIPI CSI camera port
- Audio: 4-pole stereo audio and composite video port

## Media Capabilities
- Video decoding/encoding: H.265 (4kp60 decode), H264 (1080p60 decode, 1080p30 encode)
- Graphics: OpenGL ES 3.1, Vulkan 1.0

## Storage & Power
- Micro-SD card slot for OS and data storage
- Power: 5V DC via USB-C connector (minimum 3A) or via GPIO header (minimum 3A) — the USB-C port on the Pi 4 is POWER INPUT ONLY, it does not carry video or data the way a laptop's USB-C port does
- PoE (Power over Ethernet) support available with a separate HAT accessory

## Operating Range
- Temperature: 0-50 degrees C ambient
